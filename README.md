# simple-packages-published

A simple npm package with basic math utilities.

## Installation

```bash
npm install simple-packages-published
```

## Usage

```javascript
const { add, subtract } = require('simple-packages-published');

console.log(add(5, 3));       // Output: 8
console.log(subtract(10, 4)); // Output: 6
```

## API

### `add(a, b)`
Returns the sum of two numbers.

### `subtract(a, b)`
Returns the difference of two numbers.
